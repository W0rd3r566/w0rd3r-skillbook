# Accessibility

## Use this skill when

An interface or document needs accessibility review or implementation.

## Workflow

1. Inspect semantic structure, headings, landmarks, labels, and form associations.
2. Check keyboard reachability, focus order, visible focus, and overlay dismissal.
3. Check contrast, zoom and reflow, motion preferences, and target clarity.
4. Ensure errors are identified in text and instructions do not rely on color alone.
5. Use ARIA only when native semantics are insufficient.

## Verification

Run automated checks and manually test keyboard navigation and screen-reader semantics; record scope.

## Boundaries

Automated tools cannot certify accessibility. Avoid redundant or conflicting ARIA.
