# Frontend Development

## Use this skill when

Frontend features, components, pages, or interactions.

## Workflow

1. Inspect framework, routing, state management, styling, build scripts, and existing components.
2. Follow local conventions and reuse components where appropriate; avoid needless dependencies.
3. Keep state explicit and derive display state from a clear source of truth.
4. Handle loading, error, empty, and success states; validate input at boundaries.
5. Use semantic HTML and preserve responsive layout and keyboard interaction.

## Verification

Run typecheck, lint, tests, and production build where available; verify key interactions and breakpoints.

## Boundaries

Do not replace frameworks or styling systems without approval. Do not claim placeholder controls work.
