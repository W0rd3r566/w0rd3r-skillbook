# UI/UX Design

## Use this skill when

Designing or improving a screen, flow, interaction, or user experience.

## Workflow

1. Identify user, primary task, context, constraints, and success condition.
2. Map the shortest clear flow and identify decisions, errors, and recovery paths.
3. Prioritize content hierarchy and action clarity before decoration.
4. Specify loading, empty, error, disabled, confirmation, and success states.
5. Use familiar interaction patterns unless a new pattern has a clear benefit.

## Verification

Walk through primary and failure paths; check responsive behavior, keyboard navigation, and label clarity.

## Boundaries

Do not invent user research or analytics. Separate observed evidence from assumptions.
