# Design System

## Use this skill when

Shared visual tokens, component standards, or design-system cleanup.

## Workflow

1. Inventory existing colors, typography, spacing, radii, elevations, and component patterns.
2. Identify genuine repetition and inconsistency before introducing abstractions.
3. Define semantic tokens by purpose instead of scattering raw values.
4. Specify component variants, states, accessibility expectations, and examples.
5. Migrate incrementally while preserving behavior.

## Verification

Check representative screens for consistency, contrast, responsiveness, and documented component states.

## Boundaries

Do not create tokens for every one-off value or force unrelated screens into identical layouts.
