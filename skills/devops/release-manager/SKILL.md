# Release Manager

## Use this skill when

Preparing a version, release, tag, changelog, or distribution package.

## Workflow

1. Inspect versioning, changelog, CI status, release process, and compatibility policy.
2. Collect changes and known issues from verified commits or supplied context.
3. Check tests, build artifacts, dependency metadata, licenses, and platform support.
4. Prepare concise notes with breaking changes and migration steps clearly identified.
5. Confirm tag, branch, artifact names, and publication target before release actions.

## Verification

Verify exact commit and artifacts intended for release; run relevant checks and provide provenance when needed.

## Boundaries

Do not publish, tag, upload, or announce without authorization. Never invent changelog entries.
