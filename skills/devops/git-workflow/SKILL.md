# Git Workflow

## Use this skill when

Branching, commits, rebasing, merging, conflict resolution, or pull requests.

## Workflow

1. Inspect branch, status, remotes, recent commits, and uncommitted changes first.
2. Keep changes scoped and preserve unrelated user modifications.
3. Use clear commit messages that describe intent; separate unrelated changes.
4. Resolve conflicts by understanding both sides and preserving intended behavior.
5. Summarize changed files, tests, and follow-up in the pull request.

## Verification

Review diff, status, commit contents, branch, and remote before finalizing.

## Boundaries

Never force-push, reset, clean, or discard user changes without explicit approval.
