# Technical Documentation

## Use this skill when

READMEs, guides, API references, architecture notes, and contribution docs.

## Workflow

1. Identify reader and task the document should help complete.
2. Verify commands, paths, versions, options, and feature claims against the project.
3. Organize from quick start to reference; make prerequisites and expected output explicit.
4. Use safe copyable examples and explain placeholders and platform differences.
5. Update related docs when behavior or installation steps change.

## Verification

Check links, code fences, commands, and consistency with implementation; run examples when available.

## Boundaries

Do not invent features, benchmarks, compatibility, or successful test results.
