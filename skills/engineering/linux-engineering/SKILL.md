# Linux Engineering

## Use this skill when

Linux-specific application, service, script, package, or troubleshooting tasks.

## Workflow

1. Identify distribution, init system, package manager, session context, and versions first.
2. Inspect configuration and service status before changing system state.
3. Prefer reversible, distribution-appropriate changes and explain privileged commands.
4. Use least privilege, correct ownership, secure permissions, and service isolation.
5. Separate diagnosis from remediation and back up important configuration.

## Verification

Validate syntax, inspect service status and logs, and test behavior; provide rollback for system changes.

## Boundaries

Do not run destructive commands or overwrite system files without approval. Never assume a package manager.
