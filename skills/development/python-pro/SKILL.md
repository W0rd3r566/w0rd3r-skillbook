# Python Pro

## Use this skill when

Python implementation, debugging, review, or refactoring.

## Workflow

1. Inspect Python version, packaging, formatter, linter, type checker, and local conventions.
2. Prefer explicit code and standard-library tools when appropriate.
3. Add useful type hints at public boundaries and validate dynamic input at runtime.
4. Handle expected failures explicitly; do not swallow broad exceptions or log secrets.
5. Keep functions cohesive and dependencies justified.

## Verification

Run available format, lint, type-check, and test commands. List exactly what ran.

## Boundaries

Do not upgrade runtimes or dependencies without reason. Never claim checks ran when they did not.
