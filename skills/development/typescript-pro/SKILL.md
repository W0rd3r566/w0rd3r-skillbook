# TypeScript Pro

## Use this skill when

TypeScript or JavaScript implementation, review, or refactoring.

## Workflow

1. Inspect tsconfig, package manager, runtime, framework, and local conventions.
2. Use explicit types for public APIs and complex boundaries; infer local types naturally.
3. Model variants with discriminated unions and narrow unknown input at runtime.
4. Avoid any, unsafe assertions, and duplicated type definitions.
5. Keep async failures observable and clean up subscriptions and resources.

## Verification

Run typecheck, lint, tests, and build where available; report exact results.

## Boundaries

Types do not replace runtime validation. Do not change compiler settings or package managers casually.
